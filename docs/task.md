## 検証で見つけて直した不具合

| 内容 | 対応 |
|------|------|
| AI 応答後に回答を記録していたため、解説を待たず次へ進むと回答が消える | タップ時点で同期的に記録・永続化し、誤答タイプのみ後追いで追記する構造に変更 |
| 選択肢の連打で 1 問が二重に登録される（10 問セットが 11 問になる） | state ではなく ref でガードし、同一問題の 2 回目以降を無視 |
| フォールバック時、意味選択では誤答タイプが常に「記憶があいまい」になる | 選ばれた日本語の意味から語を逆引きし、類似語・品詞・場面で判定するよう修正 |
| 誤答カルテの百分率が 63% + 38% = 101% になる | 最大剰余法で合計を 100% にそろえる |
| 進捗ゼロのとき 700 点メーターに線端の点が残る | 到達 0 の層は描画しない |
| 推定スコアが全語習得時に 766 点になり 700 点設計と合わない | レベル重みを実データの分布に合わせて再調整（≒701 点） |
| **Web プレビューで出題対象の英単語が日本語に翻訳される**（`schedule` →「スケジュール」）。既定の HTML が `lang="en"` のため、日本語環境の Chrome がページ全体を自動翻訳していた | ルート HTML を `lang="ja"` + `translate="no"` + `notranslate` メタに変更（`app/+html.tsx` は静的書き出し用、`app/_layout.tsx` で実行時にも適用） |
| AI 不通時のフォールバック例文が品詞を無視した固定文で、名詞・形容詞では不自然な英文になる（"We need to review the customer before the meeting."） | 品詞別（動詞 / 名詞 / 名詞句 / 形容詞 / 副詞）のテンプレートに変更。全 300 語で例文に語が含まれることをテストで担保 |
| **前の問題の AI 解説が次の問題に表示される**（5 問目 `contact` の画面に 4 問目 `available` の解説）。応答が遅れて返ったときに問題番号を確認していなかった | 回答時の問題番号を保持し、解決時に表示中の番号と一致しなければ破棄する（MT-UI-16） |
| 総括が毎回フォールバックになる。原因は **Gemini 無料枠の 1 日 20 リクエスト超過**（1 セットで 12 回消費）。→ 消費回数の削減（上記）で根本対応 | 429 を「分あたり」と「1 日あたり」に区別。分あたりは総括に限り最大 35 秒待って再試行、日次上限は待たずに諦める。理由別の案内文と再取得ボタンを追加。消費回数そのものの削減は仕様変更のため未実施 |
