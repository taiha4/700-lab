## このプロジェクト固有として足したもの

- **冒頭に「3 つの課題と回答」の表** — このアプリの存在意義そのものなので、機能追加の判断基準として最初に置きました。
- **実装フローに 2 項目追加** — 「仕様変更が発生したら都度 `spec.md` に追記」（グローバル設定のルール）と、「画面を変更したら実際に動かして目で確認する」。回答の取りこぼし・連打の二重登録・数値の不整合は、いずれもユニットテストでは出ず実走で見つかったためです。
- **壊してはいけない設計判断を明記** — 特に次の 3 点は、リファクタで素直に「直す」と機能が壊れます。
  - 回答の記録は AI 応答前に確定させる（順序を戻すと回答が消える）
  - `dominantErrorType` → `buildChoices` の依存を切らない（誤答カルテがただの円グラフに退化する）
  - `lang="ja"` + `notranslate` を外さない（英単語がブラウザ翻訳される）
- **実データに基づく制約** — `similar` 列 860 語のうちマスタに実在するのは 101 語で、混同対策の主戦場は `use` 形式である、という調査結果を残しました。
- **バージョン固定の注意** — `jest-expo` / `babel-preset-expo` を最新の 57 系にすると SDK 54 では起動しません（構築時に実際に踏みました）。

なお、タスクファイルは KouxaPlatform_2 の `docs/tasks.md` に対し、こちらは `docs/task.md`（単数）です。参照先はすべて実ファイル名に合わせています。

## 内容

単なる会話の書き起こしではなく、**判断とその理由**を軸に構成しました。

1. **仕様策定** — 単語データの実測（類似語 860 語中マスタ実在は 101 語）や参考デザインの抽出
2. **実装** — SDK 54 へのバージョン固定でつまずいた点、フォント不採用（3.8MB）の理由
3. **検証と修正** — 見つけた不具合 5 件と原因
4. **日本語化問題** — Chrome 自動翻訳が原因と特定した経緯
5. **CLAUDE.md 作成** — 壊してはいけない設計判断の明記
6. **再検証** — 解説の混入バグ、無料枠 1 日 20 リクエストの発見
7. **API 削減** — 12 回 → `1 + 誤答数 + 1` 回、実測 8 回
8. **GitHub 公開** — 機密スキャンと `gh` 再導入

末尾に、仕様の版数推移（v1.0〜v1.6）、テスト件数の推移（55 → 89）、不具合 10 件の一覧、未完了項目、振り返りを付けています。

振り返りでは、**不具合 10 件中 7 件がユニットテストでは検出できず実走で見つかった**こと（いずれも非同期処理と画面遷移が絡む箇所）と、API の無料枠という外部制約が設計そのものを変えた経緯を残しました。

記載した数値（テスト 89 件・ファイル 60 件・仕様 v1.6）は実際の状態と照合済みです。あわせて `CLAUDE.md` と `README.md` のドキュメント一覧にも参照を追加しました。
