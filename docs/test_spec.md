### Web プレビュー時の注意（重要）

既定の Web ビルドは `<html lang="en">` で配信されるため、日本語環境の Chrome が**ページ全体を英語→日本語へ自動翻訳し、出題対象の英単語まで置き換えてしまう**（`schedule` →「スケジュール」）。`app/_layout.tsx` と `app/+html.tsx` で `lang="ja"` と `notranslate` を指定して無効化済み。
