# 700 Lab

**今日の15分が、700点をつくる。**

TOEIC 700 点突破を目指す社会人向けの英単語アプリ（Expo / React Native）。
通勤 30 分・昼休み 15 分のスキマ時間で、1 セット 10 問・約 10 分で完結します。

## このアプリが解こうとしている 3 つの課題

| 課題 | 回答 |
|------|------|
| 「覚えた」と「使える」は別物 | 1 語を **認識 / 運用の 2 段階**で管理。意味の 4 択に正解しても「分かる」止まりで、ビジネス文脈の穴埋めに正解して初めて「使える」に昇格します |
| 間違えた原因が分からない | 不正解時に Gemini が **4 タイプ（類似語の混同 / 品詞の取り違え / 記憶があいまい / 文脈の読み違い）** に分類し、先生の口調で理由と見分け方を返します |
| 続けても実感がない | 学習状態から **700 点メーター（推定到達スコア）** を算出。セット終了時に `450.0 → 450.9（+0.9 pt）` と差分で提示します。計算式はアプリ内で公開しています |

### 既存の単語アプリにない仕掛け

**誤答カルテが出題内容を書き換えます。** 誤答タイプを集計して見せるだけでなく、最頻タイプに応じて**選択肢のダミー生成ロジック自体が変化**します（類似語の混同が多い人には `require / request / demand` のような紛らわしい語が優先的に混ざる）。分析 → 出題への還元ループが、このアプリの核です。

## セットアップ

```bash
npm install

# Gemini API キーを設定（未設定でも学習は動作します）
cp .env.example .env
# .env の EXPO_PUBLIC_GEMINI_API_KEY にキーを記入

npm start          # Expo Go で QR を読み取って起動
```

キーはアプリの「設定」画面からも入力できます（端末内 `AsyncStorage` に保存）。

> ログイン・サーバーを持たない構成のため、API キーは端末側に置きます。学習・デモ用途を想定した設計です。

## コマンド

| コマンド | 内容 |
|----------|------|
| `npm start` | Expo 開発サーバー（Expo Go 用） |
| `npm test` | ユニットテスト（79 件） |
| `npm run typecheck` | TypeScript 型チェック |
| `npm run build:wordlist` | `doc/toeic_wordlist.xlsx` → `src/data/toeic_wordlist.json` を再生成 |

## 構成

```
app/                  expo-router の画面
  (tabs)/             ホーム / 進捗 / 単語帳 / 設定
  session/            出題・総括
  word/[id].tsx       単語詳細
src/
  data/               単語マスタ 300 語（xlsx から生成）
  domain/             出題選定・間隔反復・スコア・集計（純粋関数・テスト対象）
  ai/                 Gemini クライアント / プロンプト / フォールバック
  storage/            AsyncStorage ラッパ
  context/            WordsProvider
  components/         共通 UI・二層ゲージ・誤答カルテ
```

## 設計上の要点

- **AI が落ちても学習は止まりません。** タイムアウト 12 秒 → 1 回再試行 → フォールバック表示。オフラインでも出題・回答・進捗更新はすべて動作します。
- **回答はタップした瞬間に永続化されます。** AI の解説を待たずに次へ進んでも記録は失われません（誤答タイプだけを後から追記します）。
- **全データは端末内**にのみ保存されます。Gemini へ送るのは、その問題の単語・ユーザーの回答・学習統計だけです。
